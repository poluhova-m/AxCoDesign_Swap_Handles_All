# AxCoDesign_Swap_Handles_All

Макрос для Tekla Structures, который разворачивает направление деталей — меняет местами их начальную и конечную точки — **без удаления и пересоздания детали**.

## Зачем

Штатно поменять начало и конец детали можно только удалив её и создав заново. При этом приходится заново заполнять атрибуты и восстанавливать всё, что к детали прикреплено: подрезки, обработки поверхности, плагины, компоненты. В зависимости от сложности детали это занимает от 5 минут до 2–3 часов.

Макрос делает то же самое меньше чем за секунду для любого количества выделенных объектов. Деталь сохраняет свой идентификатор, атрибуты и все связанные элементы.

## Что делает

| Тип объекта | Действие |
|---|---|
| Балка (`Beam`) | Меняет местами `StartPoint` и `EndPoint`; переставляет усилия на концах — атрибуты `BM_FORCE1` и `BM_FORCE2` |
| Полибалка (`PolyBeam`) | Разворачивает список точек контура в обратном порядке; переставляет `BM_FORCE1` / `BM_FORCE2` |
| Контурная пластина (`ContourPlate`) | Сдвигает начальную точку контура — ориентация меняется, геометрия остаётся прежней |
| Вырез контурной пластиной (`BooleanPart`) | То же для пластины, которой выполнен вырез |

Все изменения применяются через `Modify()` и один общий `CommitChanges()`.

## Установка

1. Скопируйте файл `AxCoDesign_Swap_Handles_All.cs` в папку макросов моделирования. Путь к ней задан расширенной опцией `XS_MACRO_DIRECTORY`, макрос кладётся в подпапку `modeling`.
2. Перезапустите Tekla Structures или обновите список макросов.

## Использование

1. Выделите в модели нужные балки, полибалки или пластины.
2. Запустите макрос **AxCoDesign_Swap_Handles_All** из списка макросов.

## Технологии

C#, Tekla Open API, макросы Tekla Structures (`Tekla.Technology.Akit`).

Метод `Main` позволяет отлаживать логику как консольное приложение с подключёнными сборками Tekla Open API.
